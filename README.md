# 🐱 蛋殼貓 APNG 工具 (EggshellCat APNG Tool)

一個純前端、隱私優先的 APNG 動畫產生工具。
把一序列 PNG 圖片打包成動畫 PNG（APNG），**所有處理都在你瀏覽器本機完成，圖片絕不上傳伺服器**。

---

## ✨ 功能特色

- 🔒 **純本機處理** — 圖片不上傳，敏感素材也能安心用
- 🎞️ **自訂每格延遲** — 每一格可以分別設定毫秒數
- 🔁 **真實循環次數** — 直接修改 APNG 的 `acTL` chunk，瀏覽器外的播放器會正確播放
- 📐 **等比縮放** — 設寬度自動算高度，反之亦然
- 🎨 **可選色彩深度** — 全彩 24bit 或 256 色壓縮
- 🖼️ **即時預覽** — 拖圖進去立刻看到，時間軸可跳格
- 📦 **免費無廣告** — 完全免費，沒有任何廣告

---

## 🚀 怎麼使用

### 線上版（免費使用）
打開 `apng.html` 即可使用，不需要安裝任何東西。

### 操作步驟
1. 把 PNG 圖片拖曳到虛線框（可多選，依檔名排序 frame01.png, frame02.png...）
2. 設定 FPS（影格速率）或自訂每格延遲
3. 設定循環次數（0 = 無限）
4. 設定輸出寬高（留空 = 原圖大小）
5. 點「產生 APNG」→ 下載 PNG

## 🔧 進階功能

### 自訂每格延遲
在「自訂延遲」欄位輸入逗號分隔的毫秒數：
```
100,100,300,100,100
```
代表：第 1、2、5 格各 100ms，第 3 格停 300ms，第 4 格 100ms。

### 真實循環次數
UPNG.js 本身不支援 loops 參數，本工具會在編碼後直接修改 APNG 檔案的 `acTL` chunk，把 `num_plays` 欄位改成你指定的次數，並重算 CRC。
