 怎麼用

  1. 把 PNG / APNG / GIF 拖到虛線框（可多選）
  2. 在每張縮圖卡片上調整該格的延遲毫秒（預設 100ms）
  3. 用卡片下方的 ⏮ ◀ ▶ ⏭ 按鈕調整影格順序，✕ 刪除不需要的格
  4. 設定循環次數與色彩深度
  5. 需要縮放才填輸出寬高，留空 = 原圖大小
  6. 點「生成 APNG」→「下載 PNG」

 小提示

  1. 拖入現成的 APNG / GIF 會自動拆成影格並還原時間
  2. 右上的棋盤格 / 黑色按鈕可以切換預覽背景，方便看透明邊緣
  3. 所有圖片都在你瀏覽器本機處理，不會上傳
  4. 輸出的 PNG 是 APNG 格式，丟 Discord / Telegram / LINE 都會動

 LINE 動態貼圖限制

  1. 動畫播放時間必須是整數秒（1、2、3、4 秒）
  2. 動畫播放時間不可超過 4 秒
  3. 圖片寬或高其中一邊必須為 270px，且在 320×270 以內
  4. 影格數量限制為 5～20 格
  5. 重複播放次數：每張動態貼圖 1～4 次
  6. 每張圖片的檔案大小須小於 1MB

 常見問題

 APNG 跟 GIF 有什麼不同？

APNG（Animated PNG）支援完整透明與 24 位元色彩＋8 位元 alpha；GIF 只有 256 色與 1 位元透明。要做邊緣柔和、帶透明陰影的動畫，APNG 的畫質明顯更好，檔案通常也更小。

 怎麼讓輸出的檔案變小？

在「基本設定」把色彩改成 256 色或 128 色（全彩檔案最大）；也可以減少影格數量，或在「輸出尺寸」填比較小的寬高。本工具沒有 lossy 壓縮滑桿，縮小檔案就是靠這三個方式。

 我的圖片會被上傳嗎？

生成、拆格、縮放、去背全部在瀏覽器本機用 Canvas 完成，圖片不會離開你的電腦。只有你主動按「分享我的圖片」時，檔案才會上傳到 Meme 展示牆，而且要經過審核才會公開顯示。

 可以把現成的 GIF 或 APNG 丟進來改嗎？

可以。拖進現成的 APNG 會逐格讀取 fcTL 的延遲時間拆成影格；GIF 用 omggif 解碼，會依 disposal 方式正確合成，不會出現殘影或斑點。

 輸出後在 LINE 上不動或傳不上去？

生成後會自動檢查 6 項 LINE 動態貼圖規範：總時間須為整數秒且不超過 4 秒、寬或高其中一邊須為 270px 且在 320×270 內、影格 5～20 格、播放 1～4 次（不可無限循環）、檔案小於 1MB。沒通過的項目會列在黃色警告列。

 可以加文字或濾鏡特效嗎？

目前不支援。本工具只處理延遲、尺寸、色彩深度與循環次數；PNG 分頁可做去背、橡皮擦，並切出 LINE 用的 240×240 與 96×74。需要文字或濾鏡特效時，請先用其他軟件製作，例如 Photoshop，再把成品匯入這裡合成動畫。

 需要註冊嗎？支援哪些語言？

完全免費、免註冊，也不用安裝。介面支援繁中、簡中、English、日本語、ไทย 五種語言，預設跟隨瀏覽器語言，也可以用右上角選單手動切換。
